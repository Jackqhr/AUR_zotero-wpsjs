# AUR_zotero-wpsjs
## description
A PKGBUILD &amp; install for new version of Zotero-WPSJS Project.
## other details
this project is a support of the new version of project Zotero-WPSJS.
url: https://gitee.com/wangrui5015/Zotero-WPSJS

due to the permission limit of pamac. 

i suggest you to install it use `makepkg -si`

## usage 
1 clone this project

2 run `makepkg -si` in the project folder

3 wait

## Remark
you can adjust `pkgver` by yourself if i forget to update.

Please notice that this package will install files into wps folder in your user folder.
